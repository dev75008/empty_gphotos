    Code source et guide complet

    Trois étapes, puis le transfert.

    Aucune installation. Utilisez Chrome ou Edge récent, sur un ordinateur, et gardez cet onglet ouvert pendant le transfert.

    1. Connectez pCloud. Créez votre application pCloud une fois, enregistrez son Client ID public, puis autorisez l'accès. Aucun Client Secret n'est utilisé.
    2. Choisissez les ZIP Takeout. Demandez l'export complet sur Google Takeout. Téléchargez les parties, sans les décompresser, puis analysez-les ici.
    3. Nommez le dossier et lancez. Vous pouvez interrompre puis reprendre avec le journal conservé dans ce navigateur.

    À la fin, vérifiez les fichiers et comparez les archives traitées avec la liste Takeout. Le bilan concerne les ZIP fournis.

    Pourquoi un export Google Takeout ?

    Depuis mars 2025, l'API Google Photos ne permet plus de lire automatiquement votre photothèque existante. Takeout permet de récupérer les fichiers exportés et leurs métadonnées.

    Où sont mes fichiers et mes accès ?

    Les ZIP sont lus ici et les médias sont envoyés directement à pCloud. Le journal est enregistré dans IndexedDB ; le jeton d'accès reste dans la session de l'onglet et n'est jamais inclus dans le journal exporté. Un seul média est préparé à la fois dans l'espace temporaire privé du navigateur, puis effacé de cet espace.

    Comment reprendre après fermeture ?

    Revenez sur cette page avec le même navigateur et le même profil, reconnectez pCloud si nécessaire et sélectionnez à nouveau les ZIP utiles. Cliquez sur Reprendre le transfert. Ne supprimez pas les données du site. Sauvegardez régulièrement le journal et conservez vos ZIP : un navigateur peut effacer son stockage local.

    Voir directement les photos dans pCloud

    Les photos et vidéos sont placées directement dans le dossier choisi ; les JSON sont conservés à part dans « Métadonnées Takeout ». Si vous aviez commencé avec l’ancien rangement, mettez en pause, sauvegardez le journal, rechargez cette page puis cliquez sur « Regrouper les fichiers déjà reçus ». Aucun nouvel envoi depuis vos ZIP n’est nécessaire pour les copies reçues. Le regroupement vérifie chaque copie finale avant de retirer l’ancienne copie technique et peut reprendre après interruption. Prévoyez sur pCloud la place d’un fichier supplémentaire pendant cette étape.

    Les gros fichiers et le disque

    Il faut assez de place pour les ZIP et pour préparer le plus gros fichier individuel. Aucun ZIP complet n'est décompressé. Sans espace privé sur disque pris en charge par le navigateur, la préparation en mémoire est limitée à 128 Mo par fichier. Certaines relectures distantes peuvent être bloquées par les règles réseau de pCloud ; un fichier non contrôlé n'est pas déclaré vérifié.

    Supprimer dans Google Photos

    Ce contrôle valide les fichiers fournis, pas la totalité de votre compte Google. Cette page n’exécute aucune suppression.

    Pour automatiser les clics, téléchargez l’extension Chrome/Edge 1.1.0, installez-la selon le mode d’emploi, puis importez-y votre dossier de contrôle. Testez un média, vérifiez le résultat, puis continuez par lots dans Photos et dans Archive. Pour le dernier traitement, l’option « Vider automatiquement la corbeille après cette vue » permet d’autoriser le vidage définitif dès le lancement. Elle détruit aussi les anciens éléments de la corbeille.

    1. Dans Google Photos, vérifiez l’adresse du compte Google correspondant à l’export.
    2. Vérifiez les réglages de sauvegarde et les copies de vos téléphones et tablettes. Une suppression Google Photos peut se répercuter sur les appareils synchronisés.
    3. Sélectionnez les photos et vidéos transférées, par lots, puis choisissez Placer dans la corbeille. Confirmez dans Google. Répétez pour les éléments restants, en vérifiant aussi les archives et dossiers concernés.
    4. Conservez les éléments absents de votre export. N’utilisez pas le nombre de fichiers pCloud pour décider du nombre à supprimer : les JSON et la déduplication changent ce nombre.
    5. Ne videz pas immédiatement la corbeille. Vérifiez vos copies et le délai de restauration indiqué par Google. Une suppression définitive ne peut pas être annulée ; arrêtez-vous si Google la propose à cause d’une corbeille pleine.
